# 添加本地代理
修改.gitconfig文件 在 C:\Users\用户名 路径下

[http]
    proxy = http://127.0.0.1:7890
[https]
    proxy = http://127.0.0.1:7890


# Mac命令行中支持本地代理
必须在每个控制台中先执行一遍代理设置才能在该控制台中生效
在～/.zshrc中添加：
alias daili="export ALL_PROXY=socks5://127.0.0.1:7897"
alias undaili="unset ALL_PROXY"
这样就能执行对于的daili命令快捷开启该控制台的本地代理模式
